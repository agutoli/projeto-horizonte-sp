## Esboço inicial

Esta seção deve funcionar como o mapa técnico do projeto. Ela explica a proposta sem entrar em todos os detalhes: qual problema será investigado, qual público pode ser priorizado, como a experiência chegaria às escolas, como a Central de Oportunidades manteria continuidade e quais decisões ainda dependem de evidência.

Para uma primeira versão, a visão geral deve deixar claro que o Projeto Horizonte não é apenas uma frota de unidades móveis. O desenho compara alternativas móveis, fixas e híbridas, prioriza infraestrutura existente quando possível e só recomenda expansão se o piloto demonstrar valor.
